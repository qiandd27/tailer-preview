# TAILER website design preview

This repository contains only the public static files for a website design review shared with friends. It is a preview deployment, not the production hosting setup. The original source repository and internal reference documents remain outside this repository.

- Publishing directory: `docs/`
- GitHub Pages source: `main`, `/docs`
- Expected preview path: `/tailer-preview/`
- Original source revision: `87c2e4bf5dd8c36d9662eb76cda9eff44aef3863`
- Public catalogue: 25 product families, 72 HTML pages, 0 PDFs.
- All catalogues and full-page previews are supplied only on enquiry.
- Production-line content has been removed. Marine equipment is under Products.
- News and CMS: `/news.html`, `/admin/`; ordinary username/password accounts.
- Published content is shared through the configured Supabase project; `docs/content/site-content.json` is a release snapshot.
- Search engines are asked not to index this preview.

The content manager saves to the owner-controlled cloud backend. Editors do not need GitHub access. The administrator creates individual editor accounts, can disable access and reset initial passwords. Secret keys and passwords are never included in the website or this repository. Enquiry information is prepared in the visitor's browser and sent only through their chosen email or WeChat application. Website assets remain the property of their respective owners; publication of this preview is not a license grant.
