Electro-hydraulic deck machinery

High-pressure hydraulic drive combines a low-speed, high-torque motor and variable piston pump for stepless speed control. Options include automatic-tension mooring, brake-load monitoring and chain-length indication.

View specifications / configuration →

Electric deck machinery

AC 380/440 V, 50/60 Hz drive with an IP56 motor for exposed decks. Documented components include three-stage reduction, a spring-applied electromagnetic brake, frequency control and braking resistor, with remote-control options.

View specifications / configuration →

Self-contained electro-hydraulic deck machinery

The hydraulic power pack is integrated with the winch; pumps, cooler and accessories mount on the gear frame. Each winch can operate independently without external deck hydraulic piping. Confirm layout against onboard space and working loads.
